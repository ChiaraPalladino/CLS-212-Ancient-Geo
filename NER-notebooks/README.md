## Easy Colab Notebooks to perform NER and disambiguation with Spacy and other NLP methods

These notebooks contain simple code to experiment with textual documents containing spatial data, developed and readapted by Chiara Palladino (chiarapalladino@durham.ac.uk). 

These notebooks can be tested with files in the "data" folder, or with your own .txt file. 

The Colab notebooks readapt materials from [The Cultural Heritage AI Cookbook (2025 Edition)](https://github.com/pelagios/llm-lod-enriching-heritage), curated by Gethin Rees, many others, and myself. Since these require a Google AI Studio API key, make sure to open them in Google Colab. 

All sample texts are from [ToposTexts](https://topostext.org/index.php), with special thanks to Brady Kiesling.
